# Project Summary

This Power BI dashboard transformed fragmented spreadsheet reporting into one live sales performance view.

## Client Problem
The client needed a faster way to detect weak-performing regions without manually checking multiple files.

## My Approach
- Cleaned and organized the sales data.
- Built a Power BI model.
- Created KPIs and performance visuals.
- Added filters and highlight logic for weak regions.

## Final Outcome
The dashboard gave the client a single source of truth for sales performance and helped surface underperforming regions earlier than before.

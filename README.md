# NovaCart E-Commerce Landing Page

A mobile-first, conversion-optimized product landing page built with HTML, CSS, JavaScript, and GSAP.

## Features
- Above-the-fold CTA and product image
- Animated scroll reveals
- One-tap add-to-cart interaction
- Responsive layout
- Lightweight performance-focused structure

## Files
- `index.html`
- `styles.css`
- `script.js`

## How to run
1. Open `index.html` in your browser.
2. Or use a local server for best results.

## Suggested GitHub title
`E-Commerce Landing Page | Mobile-First Product Conversion Design`

## Client value
This landing page is designed to reduce bounce rate, guide users toward checkout, and present a polished retail brand experience.
